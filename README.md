# 岁月史书 (Book of Ages)

> 个人数字剪报本 — 收集值得记录的事件，梳理发展脉络，关联参考材料。

想象一本笔记本，你每天把看到的新闻、事件、思考剪贴进去，配上时间线和附件。
这个系统就是它的数字化版本，专门为你和 AI Agent 协作而设计。

## 核心能力

| 能力            | 说明                                                                    |
| --------------- | ----------------------------------------------------------------------- |
| **📥 收集**     | 手动录入 / URL 一键剪藏 / 书签批量导入 / Agent 通过 API 与 MCP 推送草稿 |
| **🧊 证据冻结** | 网页快照以内容寻址 (CAS) 归档，内联脚本禁用，抗 404 与篡改              |
| **📋 审批**     | 草稿进入收件箱，你浏览后一键收录；误删可从回收站恢复                    |
| **📝 整理**     | 为事件添加时间线、标签（支持层级）、参考材料                            |
| **🔍 检索**     | FTS5 全文搜索、标签筛选、时间线浏览、时间聚合分析                       |
| **🔒 安全**     | 写操作强制 API Key 鉴权、SSRF 内网防护、操作审计日志                    |

## 快速开始

### 1. 本地开发

```bash
npm install

# 启动后端 (3000) + 前端 (5173，已配置 /api 代理)
npm run dev:server
npm run dev:web
```

浏览器访问 `http://localhost:5173`。

### 2. Docker 部署

```bash
# 可选：配置管理员引导密钥（用于管理 API Key；不设置时允许匿名创建第一把密钥）
export ADMIN_API_KEY=your-admin-key

docker compose up -d --build
```

- 前端：`http://localhost`（nginx 已将 `/api` 反代至后端，同源部署无需额外配置）
- 数据持久化：`./data`（SQLite 数据库、上传材料、网页快照）

### 3. 鉴权说明

- 所有**写操作**（新增/修改/删除/上传/归档/MCP 调用）要求请求头携带 `X-API-Key`。
- 密钥在 Web「设置」页管理；浏览器本站访问密钥在「设置 → 本站访问密钥」保存（仅存于本浏览器）。
